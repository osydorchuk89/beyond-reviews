# Accessibility at Beyond Reviews

Documentation statement — 17 October 2026. At the owner's request, this statement is kept in the repository; there is no accessibility page or footer link in the app. Guidance: [W3C accessibility statements](https://www.w3.org/WAI/planning/statements/).

We are working to make Beyond Reviews usable by people with disabilities. Our target is the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA.

## Current status

Accessibility improvements are in progress. We have improved keyboard navigation, page headings, form labels and errors, rating controls, saved-item controls, action feedback, color contrast, and small-screen layouts. These improvements are being checked in the development version and are not yet confirmed on the public website.

We have not established full WCAG 2.2 AA conformance.

## Known limitations

- User messaging still has accessibility issues. We will address these when we rebuild that feature.
- Registration requirements for passwords and photo uploads are available to screen readers but are not always visible before an error occurs.
- Checks with screen readers, browser zoom, text enlargement, password managers, and Google sign-in are still needed. Some barriers may remain.

## Feedback

To report an accessibility problem or ask for help, email [oleksii.sydorchuk@gmail.com](mailto:oleksii.sydorchuk@gmail.com).

When reporting a problem, please include the page, what you were trying to do, and your browser or assistive technology if known. Do not send your password.

## How we check

We use automated accessibility checks and browser interaction tests, including keyboard navigation, failed requests, and small-screen layouts. Automated checks cannot find every accessibility issue. Manual evaluation and testing of the public website remain necessary.
